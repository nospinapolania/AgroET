# Registro de decisiones

Inicio del proyecto: 2026-10-25.
Primera revisión del registro: 2026-10-26.

Este documento registra las decisiones adoptadas para orientar
AgroET, sus motivos y las condiciones para reconsiderarlas.

Las propuestas pendientes no se consideran decisiones adoptadas.

| ID | Decisión | Justificación | Condición de revisión |
|---|---|---|---|
| D001 | Trabajar inicialmente con datos públicos. | No se dispone de acceso de campo confirmado. | Revisar si se confirma acceso a mediciones adicionales. |
| D002 | Seleccionar la variable, la zona y la metodología después de evaluar datos y bibliografía. | La pregunta debe ser científicamente pertinente y viable con la información disponible. | Reconsiderar la selección si cambia la disponibilidad de datos o aparece evidencia relevante. |
| D003 | Conservar los datos originales y documentar su procesamiento. | Es necesario distinguir valores originales, faltantes e imputados y reproducir las transformaciones. | Precisar los procedimientos cuando se seleccionen las fuentes y el diseño experimental. |
| D004 | Incorporar al historial únicamente archivos revisados y pertinentes para el proyecto. | El repositorio debe contener material comprendido, organizado y compatible con las condiciones de uso de sus fuentes. | Revisar el contenido antes de cada commit y publicación. |
| D005 | Desarrollar el proyecto por etapas con entregables verificables. | Permite comprender, revisar y documentar cada avance antes de continuar. | Ajustar las etapas si la evidencia o las necesidades del proyecto lo requieren. |

## Cómo mantener este registro

- Añadir una entrada cuando se adopte una decisión relevante.
- Explicar el motivo y la evidencia que la respalda.
- Asignar un identificador consecutivo a cada decisión nueva.
- Mantener los identificadores existentes.
- Si una decisión cambia, documentar qué la sustituye y por qué.
- Registrar tareas y avances en sus documentos correspondientes.
