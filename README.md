# AgroET

Proyecto de investigación aplicada sobre la estimación de
evapotranspiración en Perú.

El objetivo es formular y evaluar una pregunta científica mediante
datos verificables, métodos pertinentes y un diseño experimental
reproducible.

El nombre AgroET es provisional.

## Estado del proyecto

Etapa actual: 0 — Definición y organización del proyecto.

La variable de evapotranspiración, la zona de estudio, los datasets
y la metodología definitiva se seleccionarán después de evaluar
la bibliografía y la viabilidad de los datos.

Todavía no hay modelos implementados ni resultados experimentales.

La evaluación de datos y la revisión bibliográfica se desarrollarán
de forma complementaria. Sus hallazgos podrán modificar la pregunta
y el alcance del proyecto.

## Principios metodológicos

- Distinguir ET₀, ETc y ETa.
- Diferenciar observaciones de estimaciones modeladas.
- Justificar los métodos según la pregunta y los datos disponibles.
- Diseñar la validación antes de evaluar modelos.
- Evitar fugas de información.
- Documentar fuentes, decisiones, incertidumbre y limitaciones.
- Incorporar complejidad únicamente cuando esté justificada.

## Datos y reproducibilidad

Cada fuente utilizada se documentará indicando su procedencia,
variables, unidades, cobertura, resolución y condiciones de uso.

Los procedimientos de obtención y procesamiento se conservarán
para permitir la reproducción de los análisis.

Los datos grandes, privados o con restricciones de redistribución
no se incorporarán al repositorio.
